# brainstorm-safe

Skill de pre-implementación para diseño y alcance seguro en ERP/POS.

## Compatibilidad
Este skill está hecho para operar en cadena con `frontend-design`:
1. `brainstorm-safe` define alcance, riesgos y contrato de handoff.
2. `frontend-design` implementa UI/UX y código con base en ese contrato.

No reemplaza a `frontend-design`; lo prepara para trabajar con menos ambigüedad y menos retrabajo.
