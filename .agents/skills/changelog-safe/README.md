# changelog-safe

Skill seguro para generar changelogs orientados a usuario desde commits de git.

## Diferencia frente a un generador común
- No publica automáticamente.
- No ejecuta scripts externos.
- Exige trazabilidad commit -> nota.
- Siempre entrega borrador para revisión humana.

Uso recomendado: ejecutar este skill antes de publicar `CHANGELOG.md` o release notes.
